# 有问必搭 · Ask.Match

![三位同学在校园羽毛球场迎来第四位队友](doc/assets/askmatch-cover.webp)

**面向同济大学在校学生的校园活动组队工具** · 软件工程课程设计项目

## 项目简介

周五晚上想打羽毛球，问了一圈熟人，双打还差一个人。有问必搭让你发出招募、查看申请，并确认最后谁会到场。自习、桌游和聚餐等需要凑人的校园活动也适用。

我们在访谈中发现，同学对「已经约好」的理解各不相同。有人把参与讨论当作答应，有人会再确认时间和地点。有问必搭用明确的报名状态帮助发起者和参与者看清进度，尤其是计划临时变动的时候。[学生访谈归纳](doc/调研报告/有问必搭_调研回答整理.md#跨回答归纳)

## 一次活动怎么约成

1. **发布与发现。** 发起者填写活动时间、地点和人数等信息，同学可以浏览招募并申请加入。
2. **审批与确认。** 申请显示为「已提交」。发起者接受后显示「已接受」，申请者亲自确认参加后显示「已确认」。
3. **变更与退出。** 时间或地点调整时，平台通知已确认的同学重新确认或退出，并更新参加名单。

需求还涵盖校园身份验证、满员候补、活动提醒、个人资料可见设置以及举报处理。身份验证计划接入同济统一身份认证，日常登录使用平台账号。
