# 有问必搭 · Ask.Match

面向同济大学在校学生的活动组队工具，也是我们的软件工程课程设计项目。

## 项目简介

周五晚上想打羽毛球，熟人群里问了一圈，四人双打还差一个人。你可以在有问必搭发布招募，让感兴趣的同学申请加入，最后确认谁会到场。自习、桌游等需要凑人的校园活动也可以用同一套流程。

我们在访谈中发现，同学们对“已经约好”的理解各不相同。有人觉得回复同意就算约好，有人要等发起者确认，也有人要等时间和地点都定下来。有问必搭记录每一份报名的进展，让发起者和参与者都能看清谁还在等回复、谁已经确认参加。相关发现见 [学生访谈归纳](doc/调研报告/有问必搭_调研回答整理.md#跨回答归纳)。

## 一次活动怎么约成

1. **发布活动**。发起者填写活动类型、时间、地点、人数和是否 AA，同校同学可以浏览活动并提交申请。
2. **确认参加**。发起者查看申请并决定是否接受，申请者收到通知后确认是否参加。报名状态依次为 **已提交 → 已接受 → 已确认**。
3. **处理变动**。时间或地点有变化时，已确认的同学收到通知，可以重新确认或退出。取消活动时，系统通知相关同学。

课程版本优先实现这条流程，并支持查看共同可用时段和申请送达状态。当前需求草案还规划了满员候补、注册时通过同济统一身份认证验证学生身份、个人资料可见设置，以及过期活动下架和举报处理。
