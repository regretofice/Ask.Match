# 有问必“搭”用户故事清单 v0.2（草案）

- 项目：Ask.Match / 有问必“搭”
- 场景范围：**泛活动**——吃饭、拼车、自习、运动、看展、小组作业等，不限定单一活动类型
- 运营模式：**学生自治**——由学生承担运营，无专职管理员，管理人力有限
- 用户范围：**同济大学在校学生**（经学校统一身份认证准入，不开放校外与教职工）
- 版本：v0.2 草案，2026-11-24（v0.1 为 24 条；本版新增 H 域 5 条，共 29 条）
- 对应课程：第 02 课课后任务 → 第 03 课开课检查
- 责任人：组长（汇总与验收），各域负责人见 `仓库配置与分工.md`
- 状态说明：`待评审` → `已确认` → `待验证` / `不做`；评审通过后逐条建 Issue

> 口径提醒：需求是病，不是药。“要有已读”是功能，“不知道对方收到没有”才是需求。
> 本清单每一条都必须能回答一个问题：**删掉它，用户损失什么？**

## 一、编号与追溯规则

```
EV-S05-Q10      证据（受访者-问题），一题多条证据加 -a/-b
EV-O01-Q1       运营侧证据，O 系列独立编号
US-01…US-25     功能故事
NFR-01…NFR-04   非功能需求
UC-01…UC-11     用例（第 3 课）
TC-01…          测试用例（第 3 课之后）
```

1. 一个编号只出现一次，清单按编号排序，不按人排。
2. 每条故事必须挂可点击的证据行号链接，见 `证据索引.md`。
3. 每条故事最终要串成 `EV → US → UC → TC`，期末答辩固定问这条链。

### US-08 完整样例（全组照这个写）

**故事**：作为已报名的参与者，我想看到自己处于"已提交 / 已接受 / 已确认"中的哪一档，以便判断这次到底算不算约好、还要不要再问一遍。

**验收标准**

- Given 我已提交申请且发起者尚未处理，When 我打开活动详情，Then 状态显示"已提交"，并提示"尚未确认，请勿按已确认安排行程"。
- Given 发起者已接受我的申请，When 我再次打开详情，Then 状态显示"已确认"，并显示时间、地点与取消入口。
- Given 活动时间被修改，When 我尚未重新确认，Then 状态回退为"待重新确认"，不显示为"已确认"。

**证据**：S05 以"参与讨论"为确认信号；S06 以"到场"为确认信号；S09 把"已付 AA 钱"也算承诺 → 至少五种状态分裂（已邀请 / 已接受 / 已确认 / 已到场 / 已付费）。

**待决问题**："已付费"是否作为独立状态？需与名额规则、AA 规则一起评审。

> 这是全组最重要的一条，也是答辩追溯链的样板：`访谈原话 → 故事 → 验收标准 → 测试用例`。

## 十、H 域：运营与治理（学生自治运营）

> **前提**：平台由学生承担运营，无专职管理员。因此治理原则是

### 这一域的写法提醒

- **US-21 不能写成"强制实名"**。注册时走一次同济统一身份认证（SSO）确认在校身份，之后用平台自建账号登录；密码以 Argon2id 哈希存储，学号与姓名不落库（只存哈希用于查重与找回）；范围仅限本校学生。
- **US-22 的验收标准必须写清"过期"和"满员"的判定时刻**，否则自动下架会误删正在进行中的活动。
- **US-25 涉及处罚，必须有申诉入口**。O01 原话是"不能一概而论"，处罚规则不写弹性，答辩会被追问误伤。
- **US-24 要带权限最小化与操作留痕**：Given 运营账号只有举报处理权限，When 其尝试查看用户完整联系方式，Then 系统拒绝并记录审计日志。

## 十三、待决问题（评审会必须吵完）

1. "已付费"是否作为独立确认状态？（US-08）
2. 候补的时限规则：正式活动提前一天，娱乐活动随意——是否统一？（US-10）
3. "已读"要不要做？S05 自己都没分清已读与送达哪个更重要。（US-15）
4. 拉黑提示的提醒范围：只提醒自己，还是也提醒组织活动的第三人？（US-11）
5. 泛活动场景下，US-20 的"此刻"是否需要定位？——目前只写"同校 + 同一时间段"，不做定位。
6. 忘记密码只能走 SSO 重新验证重置，用户接受吗？一个学号只能绑一个账号，换号或账号被占如何处理？（US-21）
7. "无故爽约"如何判定：连续几次触发？谁举证（发起者标记 / 系统记录 / 双方互评）？（US-25）
8. 处置的申诉渠道与时限：被限制后多久可申诉、由谁复核？（US-25）
9. 自动下架的判定：以活动开始时间为准，还是以满员为准？满员后又有人退出，是否自动恢复？（US-22）
10. 举报被恶意滥用怎么处理？O01 未涉及，需补访。（US-23）
