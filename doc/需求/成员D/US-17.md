# [US-17] 活动开始前收到最新时间与地点提醒

## 编号

US-17

## 用户故事

作为已确认参加活动的学生，我想在活动开始前收到当前时间和集合地点的提醒，以便按最新安排准时到场。

## 验收标准

- Given 活动有效、我仍已确认参加且已到约定的提前提醒时点，When 提醒触发，Then 我收到包含活动名称、当前开始时间、集合地点和详情入口的站内提醒。
- Given 活动时间或地点已在提醒触发前修改，When 生成提醒，Then 使用最新安排；旧时间对应的未发送提醒不再按旧安排发出。
- Given 活动已取消或我已退出，When 原提醒时点到达，Then 不再发送普通到场提醒；必要的取消通知仍按 US-14 执行。
- Given 我因改期处于待重新确认状态，When 收到相关提示，Then 提示核对最新安排并重新确认，不将我描述为已确认参加。
- Given 同一提醒任务因失败而重复执行，When 我打开通知列表，Then 同一活动版本、同一提醒时点只出现一条对应提醒。
- Given 我从旧提醒进入活动详情，When 该活动已有后续变更，Then 展示最新状态并提示已有更新，不把旧提醒当成当前安排。

## 干系人

参与者 / 发起者（组织者）

## 优先级

P1 —— 有助于减少临出发时重复询问；删掉后用户需自行记住安排或再次联系，仍可用日历和聊天替代。

## 待决问题

1. 提前量、是否允许自定义以及临近开始才加入者如何补发，由组内评审确定；验收使用配置好的提醒时点，不将“一小时前联系”变成用户要求。
2. 常规提醒的推送渠道及关闭提醒设置需明确；不得因此屏蔽必要的变更或取消通知。
3. US-06/US-14 负责变更、取消事件；本条负责常规到场提醒，紧急变更时限见 NFR-04。
