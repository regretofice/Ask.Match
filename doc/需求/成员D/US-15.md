# [US-15] 查看申请或邀请的送达状态，减少等待中的不确定

## 编号

US-15

## 用户故事

作为发起活动或申请加入的学生，我想知道发出的申请或邀请是否已进入对方的站内消息列表，以便决定继续等待、重试还是换渠道联系。

## 验收标准

- Given 我提交了有效申请或邀请，When 服务器已保存业务记录并成功写入接收方的站内消息列表，Then 发送方可看到“已送达站内，尚未确认查看”，且该状态不代表对方已读或已接受。
- Given 申请或邀请未成功写入接收方站内消息列表，When 我查看发送结果，Then 显示“待送达”或已知的“送达失败”，不显示已送达，并在失败时提供重试入口。
- Given 请求超时且无法确定是否保存成功，When 我查看结果，Then 显示“结果待确认”，允许查询或重试；按 NFR-03 避免产生重复申请。
- Given 接收方一直没有操作，When 我刷新消息状态，Then 不因等待时间增长或推送服务受理而自动显示“已读”或“已接受”。
- Given 接收方按业务流程接受或拒绝申请，When 发送方重新查看，Then 展示对应业务处理结果；报名确认状态仍由 US-08 定义，消息送达不会自动确认参加。

## 证据强度

强：S05、S08 有状态不明与换渠道的亲身经历；S07 为偏好佐证。“送达站内”的具体定义是本稿拟议验收口径，并非用户原话。
