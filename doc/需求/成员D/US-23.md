# [US-23] 举报虚假信息、广告或爽约，并查看受理结果

## 编号

US-23

## 用户故事

作为参与者，我想对活动中的虚假信息、广告或涉嫌爽约行为提交举报并查看受理状态，以便遇到问题时有渠道反映，而不用自行公开指责或反复寻找管理员。

## 验收标准

- Given 我已登录且有权限查看目标活动或相关记录，When 我打开举报入口，Then 能选择举报对象和问题类别并填写事实说明，不强制提交与问题无关的私人资料。
- Given 我已填写有效对象、类别和事实说明，When 提交成功，Then 系统生成举报编号，显示“待处理”，我能再次查看自己的举报记录。
- Given 必填说明缺失或目标无效，When 提交举报，Then 提示需要修正的内容，不生成无效举报。
- Given 同一次举报提交结果因断网不明，When 我重复提交同一请求，Then 返回同一举报编号，不因重试生成多个工单；不同事件的举报合并规则另行评审。
- Given 我提交了一条举报，When 有处理权限的运营者查看待处理列表，Then 可以查看该举报必要信息；无关用户不能查看举报人的身份和未公开材料。
- Given 举报尚未核实，When 系统收到举报，Then 不自动认定对方违规或处罚账号；核实与分级处置衔接 US-24、US-25。
- Given 运营者已反馈处理结果，When 举报人查看记录，Then 能看到处理状态及允许公开的结果摘要，不暴露对方的私人资料或申诉材料。

## 干系人

参与者 / 发起者（组织者）/ 运营管理员

## 优先级

P1 —— 学生自治运营无法全量人工巡查，需要问题反馈入口；删掉后参与者只能转向外部渠道，运营者难以留存和跟踪问题。

## 待决问题

1. 举报资格、类别、必填事实与可选附件由组内评审确定；涉嫌爽约不等同已经判定无故爽约。
2. 恶意举报的去重、频次限制及申诉规则需补访；不以举报数量直接处罚账号。
3. 受理时限、材料保留期限与运营权限需同 US-24、US-25、NFR-02 对齐，不承诺未经验证的处理时长。
