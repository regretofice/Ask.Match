# [US-16] 用“现在不方便”婉拒本次邀请，无需拉黑对方

## 编号

US-16

## 用户故事

作为被邀请者，我想明确表示本次不方便参加而不用拉黑对方，以便结束这次邀约的不确定，同时保留以后正常联系的可能。

## 验收标准

- Given 我收到尚未处理的有效邀请，When 我选择“现在不方便”并提交成功，Then 本次邀请显示“已婉拒”，邀请方看到本次不能参加的结果。
- Given 我只想拒绝本次邀请，When 我提交婉拒，Then 无需填写私人原因，不自动拉黑对方，也不自动退出双方已确认参加的其他活动。
- Given 本次邀请已经婉拒，When 因网络重试再次提交同一操作，Then 保持同一婉拒结果，不重复发送同一结果通知。
- Given 邀请已撤销、已过期或已完成接受处理，When 我从旧入口尝试婉拒，Then 提示当前状态，不把已确认报名直接变成退出；退出按 US-12 执行。
