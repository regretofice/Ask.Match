# [NFR-04] 临近开始的变更通知在一分钟内可达，失败可追踪重试

## 编号

NFR-04

## 用户故事

作为临近出发的参与者，我想及时收到活动变更通知，并在渠道异常后仍能查到最新安排，以便避免按旧时间地点白跑。

## 验收标准

- Given 旧开始时间或新开始时间至少有一个落在从当前起未来 2 小时内，存在已确认者或因先前变更待重新确认且未退出者，When 时间或地点的本次有效变更保存成功（记为 t0），Then 每个上述受影响用户在 t0 后 60 秒内均可在站内查询到本次通知。
- Given 受影响用户已授权推送、设备在线且测试推送通道正常，When 上述变更保存成功，Then 其设备在 t0 后 60 秒内收到对应推送；以设备接收记录验收，不仅以推送服务受理作为到达证明。
- Given 用户离线、未授权推送或外部推送通道失败，When 本次推送未确认到达，Then 系统记录该渠道的失败、不可用或到达未知状态，不将其标为已到达；站内通知仍须在 60 秒内可查。
- Given 某渠道发生可重试失败且已恢复，When 系统执行重试，Then 能追踪本次通知与重试结果，同一变更不会新增重复站内通知；技术方案按通知标识处理重复推送。
- Given 用户在第一次变更后待重新确认且尚未退出，When 两小时内又发生一次变更，Then 仍按上述时限收到新变更通知，不因状态已不是“已确认”而遗漏。
- Given 用户从旧通知打开活动详情，When 后续变更已保存，Then 看到当前最新安排及更新提示；接收或打开通知均不自动代表重新确认参加。

## 优先级

## 待决问题

1. 原清单要求所有人 1 分钟内收到站内和推送，离线或拒绝推送时无法保证。本稿将站内时限与有前提的设备推送分开验收，属于待评审的条件澄清，不表示已经批准降低目标。
2. 暂以旧/新开始时间任一在未来 2 小时内触发；已开始活动是否适用、取消通知是否采用相同目标，需与 US-06、US-14 共同评审。
3. 失败重试间隔、次数、恢复后时限及通知过期策略需技术评审；本稿不把无限重试或必达当作保证。
4. 需选定支持的客户端和推送通道，并在测试记录中列明设备、权限、网络、时钟及实际接收时间；当前尚未实现或实测。
